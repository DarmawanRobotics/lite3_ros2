# lite3_ros2

ROS 2 Humble robot package for the Deep Robotics **Jueying Lite3**: the motion host's UDP
protocol as a ROS 2 driver, the URDF with the sensor frames, the front RTSP camera, and one
bringup launch for the Livox Mid-360 and the camera. It follows the robot package contract of
[Molly](https://github.com/DarmawanRobotics/Molly) (`src/xtras/README.md`).

Work in progress.
